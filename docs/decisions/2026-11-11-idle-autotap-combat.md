# Auto-Tap through combat progress

The user requested a broad exploit/bug hunt and balanced ongoing progression,
then clarified the primary play rhythm: **"Mostly idle, checking more than once
daily."** When asked whether to replace Auto-Tap's manual-tap requirement with
combat progress while keeping its Ascension and Rift gates, they answered
**"Use combat progress instead."**

The concrete rule was announced before implementation:
**Tireless Vigil requires 10,000 enemies defeated, 100 Ascensions, and highest
Rift 250. Online and offline kills count.**

This replaces only the 10,000-manual-tap condition from the
[30 October decision](../tasks/LAB_OFFLINE_DEED_PACING_001.md). At thirty taps
per day that former condition alone required 334 days. The change preserves
meaningful earned milestones without requiring repetitive tapping from an idle
player. Separate manual-tap Deeds, Auto-Empower requirements, all rewards and
existing Auto-Tap ownership stay intact. Existing lifetime kills count; there
is no new save field, progress reset or calendar lock.

Implementation and release status: [exploit/balance hunt](../tasks/EXPLOIT_BALANCE_HUNT_001.md).
This records the approved gameplay change, not a new repository workflow rule.
