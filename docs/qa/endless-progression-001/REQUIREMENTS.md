# User-approved requirements — 14 October 2026

The user requested an endless game that always offers stronger progression,
neither very hard nor very easy at the start, with a daily path and occasional
walls overcome by waiting for Lab projects, repeated Ascensions for the Tree,
and farming Forge upgrades. All Wisps currently unlock too early at Rift32;
maximum rarity and Ultimate are too accessible, and Ultimate is too cheap.
The user asked what comes after maximum rarity and all Wisp upgrades.

The planning conversation selected: long journey; Wisp Mastery; walls scaling
with progress; measured rebalance; depth and development requirements; explicit
farm-and-purchase Mastery; small working team day1; gameplay requirements rather
than elapsed-day gates; Prisms and Sigils as Mastery currencies.

The user then explicitly said PLEASE IMPLEMENT THIS PLAN, approving:

- Ongoing push/wall/farm/Ascend/permanent-development loop. Regular player with
  2-3 daily check-ins: Tide, Stone, early rarity and first Ascension day1; all
  eight recruits weeks3-4; first Mythic and Ultimate weeks6-8; roster development
  months; repeatable permanent Mastery thereafter. These are measured targets,
  never mandatory elapsed-day locks. Early walls hours, midgame1-2days,
  late several days, with useful farming/upgrades always available.
- Spread recruitment beyond Rift32, preserve accessible early team. Later
  rarity requires Wisp levels, Rift records, Ascension counts and completed
  Lab/Forge development. Ultimate requires Mythic, ability development, deeper
  progression and substantially more Sigils. Separate recruitment/rarity/
  Ultimate price tables to avoid accidental price changes from unlock edits.
- Mythic+ability20+Ultimate opens Mastery: each purchased rank compounds own
  Wisp Power by10%, survives Ascend and retains all prior upgrades. Spend
  Prisms/Sigils; successive ranks require deeper records and increasing
  development in uncapped Lab/Forge/Tree paths. Explicit purchases, no new timer.
  Support buff strength/duration/recast unchanged; only own Power increases.
- Create this feature task; isolate from latest accepted combined candidate.
  Extend actual-engine simulations for sessions/overnights/repeated Ascend/
  all Wisp paths. Calibrate numeric tables before rebalance; combat/income/
  prices/future Lab work may change where evidence requires it.
- Replace late exponential Lab work with bounded completion-time curve;
  resource affordability remains. Preserve already-running work and bought
  speed benefits. Add WebView60-compatible large values for progression and
  wallets beyond ordinary limits, exact accounting and established rounding.
- Persist Mastery and permanent recruitment entitlements via idempotent
  migration. Previously unlocked Wisps remain recruitable after Ascend despite
  new gates. Existing compact rarity/ability UI shows all requirements/prices/
  Current/Next; Mastery replaces completed Wisp endpoint.
- Measure fresh/developing/mature/extended campaigns under casual/frequent/
  efficient policies; free policy meets primary targets. Cover all gates,
  exact debits, write rollback, effects, retention, recovery, backups, repeated
  migration, chronology/parity, automation/Formation/Support/Prisms/paid value,
  high-rank and overflow stress, mobile/enlarged text/focus/touch/accessibility,
  existing regressions and mandatory CI.
- Integrate only after acceptance, verify APK package/signing/assets/install
  and saved upgrade, retain device limitations. Preserve recruits, rarity,
  abilities, Ultimates, currencies/upgrades/paid work. No progress reset,
  new currency, calendar lock or blanket cap removal. Separate simulations
  from human/device acceptance.

No new repository workflow rule was requested. Existing historical fixtures
and original evidence must remain intact; necessary new expectations belong to
the approved new model and require source-bound evidence, not weaker gates.
