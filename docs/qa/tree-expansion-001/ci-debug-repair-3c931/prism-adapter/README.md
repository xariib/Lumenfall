## Reproduce the historical bridge states

The diagnostic mode argument (`before-published`, `fixed-published`, or another label) only labels the output. It does not install a before/after mutation: `repro.cjs` always reads `tests/behavioral/bridge.js` from the supplied repository path. To reproduce a before result, supply an isolated checkout at `3c931a26bbcf7b009dee03e7411ed41faeb971f8`, or a checkout containing its exact original bridge (SHA256 `3a7e96895d982f005ed075334c5159b8a5e00c138475f1bc4e34b1790e978c3c`). To reproduce an after result, supply the fixed bridge (SHA256 `8568cfb994b0a6c4c1c2bded8f2946a6489b18591992e58d534f483f5cb287c1`). The optional fourth argument supplies the product source independently; omitting it reads that checkout's `index.html`. The preserved command paths describe the worktree at the time of each actual run, before or after the recorded edit. Reusing today's repaired worktree with a `before` label would exercise the repaired bridge. No new runs were performed for this clarification.
