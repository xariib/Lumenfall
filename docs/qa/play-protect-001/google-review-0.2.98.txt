Draft statement

Please review the Play Protect classification of Lumenfall 0.2.98, package
com.lumenfall.app. Lumenfall is an Android idle game distributed on GitHub.
A player reported seeing the Danish "En skadelig app er blokeret" warning
during an in-app update and confirmed that 0.2.98 was installed afterward.
The release APK hash is listed above.

The release uses the established signer and a non-debuggable production build.
The app declares INTERNET, REQUEST_INSTALL_PACKAGES for in-app updates, and
a signature-protected AndroidX receiver permission. The updater downloads the
APK and checksum from the official GitHub release, checks the APK's size,
SHA-256, package, version and signer, and hands installation to Android for
user approval. Android may show its standard Open button after installation.

The exact APK passed package, signature, configuration, emulator update and
save preservation checks. Public downloads match the tested SHA-256. These
checks provide provenance and configuration evidence. Google determines the
Play Protect classification.
