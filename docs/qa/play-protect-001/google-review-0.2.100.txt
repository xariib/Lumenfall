Draft statement

Please review the Play Protect classification of Lumenfall 0.2.100, package
com.lumenfall.app, SHA-256 listed above. Lumenfall is an Android idle game.
A player attempting to install the signed 0.2.100 test APK from their Downloads
app saw the Danish warning "En skadelig app er blokeret". Android then reported
that the app was not installed. A separate in-app update had previously shown a
similar warning.

Version 0.2.100 is a non-debuggable production APK signed with the project's
established certificate. It declares INTERNET, REQUEST_INSTALL_PACKAGES for
the app updater, and a signature-protected AndroidX receiver permission. The
updater uses the official GitHub release feed and verifies size, SHA-256,
package, version and signer before handing the update to Android for approval.

The exact test APK passed package, signing, static configuration, emulator
upgrade and retail Android launch checks. The updater's emulator test also
passed retry, launch from Android's Open button, and preservation of both save
slots. These checks document the build and its behavior. Google determines the
Play Protect classification.
