# Lumenfall

Android idle RPG. Build your Wisp party, conquer the Rift and Ascend.

**[Download APK](https://github.com/xariib/Lumenfall/releases/latest/download/Lumenfall.apk)**

Install as an update. **Do not uninstall** — keep your progress.
Backup: Settings → Save Backup.

In-app updates: Settings → App updates. The app checks for new versions when
you play. Tap **Download & install**, then approve the Android installation.
If Android asks, allow Lumenfall to install the update. Your saves stay in place.
